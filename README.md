
# Plastic Bottle Anomaly Detection on Conveyor Belt

Dự án ứng dụng thuật toán Anomaly Detection để tự động phát hiện các chai nhựa lỗi trên hệ thống băng chuyền. Mô hình được huấn luyện bằng cách phân loại các mẫu ảnh bình thường và bất thường theo thời gian thực.

## Dữ liệu (Dataset)
Dữ liệu huấn luyện của dự án được lưu trữ và quản lý trên Kaggle:
🔗 **[Bottle Anomaly Dataset](https://www.kaggle.com/datasets/bnhonminhduy/bottle2)**
